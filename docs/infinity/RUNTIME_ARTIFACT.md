# Infinity Runtime Artifact

## Purpose

The installed SWGAide application must not require a checkout of
`swginfinity/public`.

Developer/operator tooling extracts and composes the source-backed rules once,
then commits one normalized runtime JSON artifact.

## Authority

- repository: `swginfinity/public`
- commit: `6b6ac3726aaa3c293fca83911850d3a02e2adb4f`
- SWGAide server id: `154`
- provider id: `swg-infinity`

## Packaged path

```text
src/main/resources/swg/crafting/simulator/server/infinity/weapon-ruleset.json
```

At runtime `InfinityRuntimeBootstrap` loads exactly:

```text
/swg/crafting/simulator/server/infinity/weapon-ruleset.json
```

The loader validates the normalized ruleset and enforces the pinned Infinity
commit/server through `RulesetAdmission`.

Missing or malformed artifacts fail closed.

## Generate

After a successful Java 8 compile:

```bash
source ~/.local/bin/swgaide-env.sh

java -cp target/classes \
  swg.infinity.runtime.InfinityWeaponRulesetExportMain \
  /home/thenexussidekick/swgaide-deps/swginfinity-public \
  src/main/resources/swg/crafting/simulator/server/infinity/weapon-ruleset.json \
  pistol_blaster_dl44 \
  carbine_geo \
  pistol_blaster_scout_trooper \
  rifle_berserker
```

Do not add another exact schematic ID until its complete functional parity gate
has passed.

## Validate

```bash
mvn -B -Dstyle.color=never test-compile
java -ea -cp target/test-classes:target/classes \
  swg.infinity.runtime.InfinityBundledRulesetSelfTest

java -ea -cp target/test-classes:target/classes \
  swg.infinity.FoundationSelfTestSuite
```

Record:

- generated byte size;
- SHA-256 of the artifact file;
- embedded ruleset hash;
- exact source commit;
- count of total/EXACT/PARTIAL schematics.

The generated artifact is source-derived data, not a replacement source
authority. Re-generation against a different Infinity source commit requires
semantic review and a new admission cycle.
